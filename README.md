# prog1.tri2.ativ4

O Cozinha Fácil será um site de receitas criado para facilitar a busca por diferentes tipos de pratos de forma simples e organizada. O usuário poderá criar uma conta e fazer login para acessar as funcionalidades do site. Depois de entrar, será possível pesquisar receitas pelo nome e encontrar diferentes opções de pratos para preparar. Cada receita terá informações como o nome do prato, os ingredientes necessários, o modo de preparo e uma imagem, deixando o conteúdo mais organizado e fácil de acompanhar.

Além de procurar receitas, os usuários poderão cadastrar suas próprias receitas no site, colocando informações como o nome do prato, os ingredientes necessários e o modo de preparo. Também será possível salvar receitas favoritas para encontrá-las mais facilmente depois, sem precisar pesquisar novamente. Cada usuário terá uma área pessoal onde poderá visualizar suas receitas cadastradas e suas receitas favoritas. Dessa forma, o Cozinha Fácil será um site simples e prático, que ajudará os usuários a encontrar novas receitas, guardar seus pratos preferidos e compartilhar suas próprias ideias de comida com outras pessoas.
